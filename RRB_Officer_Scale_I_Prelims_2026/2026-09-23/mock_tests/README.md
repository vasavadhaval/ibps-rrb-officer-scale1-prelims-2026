# Day 1 Mock-Test JSON Files

## Files

- `inequality_topic_test.json` - 20 questions, 12 minutes, 20 marks
- `simplification_topic_test.json` - 20 questions, 15 minutes, 20 marks

Both tests use the RRB negative-marking rule:

- Correct: +1
- Wrong: -0.25
- Unattempted: 0

## Recommended order

1. Complete the corresponding Markdown lesson and written practice questions.
2. Import only one JSON file into the mock-test website.
3. Take the test without notes.
4. Export or record the analytics.
5. Copy incorrect and slow questions into `../03_Mistake_Log.md`.

## Schema source

The structure follows the locally supplied `exam_definition_1.json`, `exam_definition_2.json` and `exam_definition_3.json` examples.

## Security note

No website username, password, token or other credential is stored in these JSON files.
