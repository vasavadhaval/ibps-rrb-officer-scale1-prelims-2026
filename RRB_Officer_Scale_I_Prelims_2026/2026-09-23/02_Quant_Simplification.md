# Quantitative Aptitude - Simplification: Complete Study Material

## 1. What this topic tests

Simplification tests calculation accuracy, operation order and number sense. These questions should become a source of fast marks. The goal is not to use a calculator-like long method; it is to recognise structure and calculate cleanly.

## 2. BODMAS rule

Use this order:

```text
B - Brackets
O - Orders: powers, roots and related operations
D/M - Division and multiplication from left to right
A/S - Addition and subtraction from left to right
```

Division does not always come before multiplication. They have equal priority and must be handled from left to right. The same rule applies to addition and subtraction.

### Example

```text
48 / 6 * 3 + 5
= 8 * 3 + 5
= 24 + 5
= 29
```

## 3. Fractions

### Addition and subtraction

Use a common denominator:

```text
2/3 + 5/6
= 4/6 + 5/6
= 9/6
= 3/2
= 1.5
```

### Multiplication

Cancel common factors before multiplying:

```text
5/8 of 384
= 5/8 * 384
= 5 * 48
= 240
```

### Division

Multiply by the reciprocal:

```text
3/4 / 5/8
= 3/4 * 8/5
= 6/5
```

## 4. Percentages

`x%` means `x/100`.

```text
25% of 320 = 1/4 of 320 = 80
18% of 450 = 10% + 8% = 45 + 36 = 81
```

Useful conversions:

| Fraction | Percentage |
|---|---:|
| 1/2 | 50% |
| 1/3 | 33.33% |
| 1/4 | 25% |
| 1/5 | 20% |
| 1/6 | 16.67% |
| 1/8 | 12.5% |
| 1/10 | 10% |
| 3/4 | 75% |
| 5/8 | 62.5% |

## 5. Decimal shortcuts

Convert simple decimals to fractions when useful:

```text
0.5 = 1/2
0.25 = 1/4
0.75 = 3/4
1.25 = 5/4
2.5 = 5/2
```

Example:

```text
1.25 * 64
= 5/4 * 64
= 5 * 16
= 80
```

## 6. Powers and roots

Memorise squares at least through 40 and cubes through 20.

```text
sqrt(144) = 12
sqrt(625) = 25
cube root of 125 = 5
cube root of 729 = 9
```

## 7. Algebraic identities that save time

```text
a^2 - b^2 = (a-b)(a+b)
```

Therefore:

```text
(15^2 - 9^2) / (15 - 9)
= ((15-9)(15+9)) / (15-9)
= 15 + 9
= 24
```

## 8. Cancellation rules

Cancellation works across multiplication and division, not across addition or subtraction.

Valid:

```text
(25 * 16) / 5 = 5 * 16 = 80
```

Invalid:

```text
(25 + 10) / 5
```

You cannot cancel 25 with 5 while ignoring the `+10`. First simplify the numerator: `35/5 = 7`.

## 13. Common mistakes

- Ignoring brackets.
- Performing addition before multiplication.
- Forgetting the left-to-right rule for division and multiplication.
- Moving the decimal point incorrectly.
- Cancelling across addition or subtraction.
- Using approximation when the question requires an exact value.
- Spending too long on one calculation instead of skipping and returning later.
